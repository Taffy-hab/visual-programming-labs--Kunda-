# Экспорты TypeBot — lab5

## ВАЖНО

Файлы в этой папке **сейчас являются примерами**, сгенерированными без доступа
к вашему аккаунту TypeBot. В каждом JSON есть поля:

```json
"example": true,
"_warning": "ПРИМЕР ЭКСПОРТА..."
```

Их нужно заменить реальными экспортами после выполнения ручных шагов.

## Как получить реальный экспорт

1. Войдите в https://app.typebot.io/.
2. Откройте workspace `lab5-Kunda-SDP-UIR-241`.
3. Откройте бота `lab5-Kunda-SDP-UIR-241-bot`.
4. В редакторе нажмите **More (…) → Export → JSON**.
5. Скачанный файл переименуйте в
   `flow-01-Kunda-SDP-UIR-241-typebot.json` и замените пример.
6. Удалите поля `example` и `_warning` из нового файла, если они там есть.
7. Сделайте коммит, например:

   ```bash
   git add lab5/exports
   git commit -m "lab5: replace example export with real typebot export"
   git push
   ```

## Требования к именам

Все имена содержат фамилию и группу:

- фамилия: `Kunda`;
- группа: `SDP-UIR-241` (транслитерация `СДП-УИР-241`).

Если в TypeBot вы использовали кириллические имена, приведите их к тому же
стилю в отчёте и скриншотах.
