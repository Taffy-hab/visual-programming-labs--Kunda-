# 05 — Условие Condition

**Итоговый файл:** `05-condition.png`

## Что должно быть видно

- блок **Condition** в редакторе;
- переменная `user_group`;
- оператор `contains`;
- значение `СДП-УИР-241`;
- две ветки: успех и ошибка.

## Как сделать

1. Добавьте блок **Condition** после ввода группы.
2. Настройте правило: `user_group contains СДП-УИР-241`.
3. В ветку «да» добавьте текст про успех, в ветку «нет» — про ошибку.
4. Сделайте скриншот редактора условия.
5. Сохраните как `lab5/screenshots/05-condition.png`.
