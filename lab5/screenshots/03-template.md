# 03 — Выбор шаблона

**Итоговый файл:** `03-template.png`

## Что должно быть видно

- галерея шаблонов TypeBot;
- выбранный шаблон **Lead Generation** (или **FAQ**);
- поле имени бота `lab5-Kunda-SDP-UIR-241-bot`.

## Как сделать

1. В workspace нажмите **Create bot / New typebot**.
2. Введите имя `lab5-Kunda-SDP-UIR-241-bot`.
3. В галерее выберите **Lead Generation**.
4. До нажатия **Use template** сделайте скриншот.
5. Сохраните как `lab5/screenshots/03-template.png`.
