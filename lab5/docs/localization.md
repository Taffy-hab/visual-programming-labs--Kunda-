Исходный шаблон: **Lead Generation** (при отсутствии — **FAQ**).
Все тексты ниже переведены на русский язык. Имена переменных и технические
идентификаторы оставлены на латинице, чтобы не сломать логику флоу.

## Переменные

| Имя переменной | Назначение | Пример значения |
|---|---|---|
| `user_name` | Имя пользователя | `Иван Кунда` |
| `user_group` | Группа пользователя | `СДП-УИР-241` |
| `contact` | Контакт для связи | `kunda.sdp-uir-241@example.com` |

> Тестовый адрес выше — вымышленный, используется только как пример тестовых данных.

## Условие Condition

Логика: если `user_group` содержит `СДП-УИР-241`, идём в ветку успеха,
иначе — в ветку ошибки.

```text
ЕСЛИ user_group СОДЕРЖИТ "СДП-УИР-241"
  ТО -> показать "Отлично, Кунда из группы СДП-УИР-241 — данные приняты"
  ИНАЧЕ -> показать "Группа не распознана. Укажите группу в формате СДП-УИР-241"
```

## Как проверить, что логика не сломалась

1. Откройте бота в редакторе и нажмите **Preview / Тест**.
2. Введите имя `Иван Кунда`.
3. Введите группу `СДП-УИР-241`.
4. Убедитесь, что открылась ветка успеха, а не ошибка.
5. В панели **Variables** проверьте значения:
   - `user_name = Иван Кунда`
   - `user_group = СДП-УИР-241`
6. Введите группу `TEST-241` и убедитесь, что сработала ветка ошибки.
7. Проверьте, что после успешной ветки срабатывает HTTP Request
   и на `webhook.site` появляется POST с полями `user_name`, `user_group`, `bot`.
