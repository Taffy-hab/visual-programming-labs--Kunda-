# Публикация бота lab5-Kunda-SDP-UIR-241-bot

В документе собраны все варианты публикации. Выберите хотя бы один —
web-ссылки достаточно для защиты.

## Вариант 1 — публичная web-ссылка (рекомендуется)

1. В редакторе TypeBot нажмите **Publish / Опубликовать**.
2. Скопируйте ссылку вида `https://typebot.io/xxxxxxxx`.
3. Вставьте её в [`report.md`](report.md) вместо плейсхолдера
   `ЗАМЕНИТЕ-НА-ВАШ-PUBLIC-ID`.
4. Проверьте ссылку в приватном окне браузера: диалог должен открыться без входа
   в аккаунт TypeBot.
5. Сделайте скриншот `08-channel-telegram.png` (или отдельный
   `08-public-link.png`, если используете только web-вариант).

## Вариант 2 — встраивание на сайт

TypeBot даёт готовый iframe-код. Пример с вашими данными:

```html
<iframe
  src="https://typebot.io/ЗАМЕНИТЕ-НА-ВАШ-PUBLIC-ID"
  width="100%"
  height="600"
  frameborder="0"
  title="lab5-Kunda-SDP-UIR-241-bot"
></iframe>
```

Можно также использовать официальный TypeBot Embed SDK, если нужно
встраивание всплывающим окном.

## Вариант 3 — Telegram-канал

1. Откройте чат с [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Введите отображаемое имя:

   ```text
   lab5 Kunda SDP UIR 241 bot
   ```

4. Введите username:

   ```text
   lab5_Kunda_SDP_UIR_241_bot
   ```

5. Скопируйте полученный токен.
6. В TypeBot откройте бота → **Channels / Каналы** → **Telegram** → вставьте токен.
7. Найдите бота в Telegram по username и отправьте `/start`.
8. Сделайте скриншот диалога и сохраните как `08-channel-telegram.png`.

> **Важно:** токен Telegram — это секрет. Не вставляйте его в код, JSON, отчёт
> и не коммитьте в репозиторий. В JSON-экспорте оставлен только username/ссылка.

## Вариант 4 — тестовый webhook вместо реального сервиса

Если нет реального API:

1. Откройте https://webhook.site/.
2. Скопируйте свой уникальный URL.
3. Вставьте его в блок Webhook в TypeBot.
4. Пройдите диалог и убедитесь, что POST-запрос появился в списке запросов.
5. В реальном экспорте замените
   `https://webhook.site/REPLACE-WITH-YOUR-UNIQUE-ID` на ваш адрес.
