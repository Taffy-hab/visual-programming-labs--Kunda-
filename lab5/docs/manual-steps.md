## 1. Русификация шаблона по блокам

В редакторе слева/в центре вы видите **группы блоков** (колонки) и сами блоки.
Чтобы изменить блок — кликните по нему, справа откроется панель настроек.

Проходите по блокам сверху вниз.

### 1.1. Блок Start

1. Кликните стартовый блок.
2. Если у него есть поле Label, введите:

   ```text
   Начало диалога — Кунда, СДП-УИР-241
   ```

3. Если поля Label нет — просто пропустите.

### 1.2. Приветственный Text-блок

1. Кликните первый текстовый блок после Start.
2. В поле текста удалите английский и вставьте:

   ```text
   Привет! Я бот lab5-Kunda-SDP-UIR-241-bot. Давайте познакомимся — это займёт меньше минуты.
   ```

3. Если в шаблоне есть отдельный блок-описание, замените его на:

   ```text
   Зададим несколько коротких вопросов — это займёт меньше минуты.
   ```

### 1.3. Первый Input — имя

1. Кликните блок ввода имени (обычно вопрос `What is your name?`).
2. В поле вопроса введите:

   ```text
   Как вас зовут?
   ```

3. В поле Placeholder введите:

   ```text
   Например, Иван Кунда
   ```

4. В поле кнопки введите:

   ```text
   Отправить
   ```

5. В поле **Variable** создайте или выберите `user_name`:
   - нажмите на поле Variable;
   - **New variable / Новая переменная**;
   - имя строго: `user_name`;
   - Enter.
6. В поле сообщения об ошибке (Invalid message / Error) введите:

   ```text
   Пожалуйста, введите корректное значение
   ```

### 1.4. Второй Input — группа

В шаблоне Lead Generation вторым обычно идёт ввод email. Переделайте его под группу.

1. Кликните второй блок ввода.
2. Вопрос замените на:

   ```text
   Укажите вашу группу
   ```

3. Placeholder:

   ```text
   Например, СДП-УИР-241
   ```

4. Кнопка:

   ```text
   Продолжить
   ```

5. В поле **Variable**:
   - если там стоит `email` — либо переименуйте переменную в `user_group`
     через панель Variables, либо создайте новую `user_group` и выберите её;
   - имя строго: `user_group`.
6. Сообщение об ошибке:

   ```text
   Группа не распознана. Укажите группу в формате СДП-УИР-241
   ```

### 1.5. Остальные кнопки и тексты

Замените по таблице:

| Было | Стало |
|---|---|
| `Send` | `Отправить` |
| `Continue` | `Продолжить` |
| `Learn more` | `Узнать подробнее` |

4. Убедитесь, что в блоках Input выбраны именно `user_name` и `user_group`.
5. Закройте панель Variables.

## 3. Условие Condition

Добавьте условие после ввода группы.

1. Найдите блок `Укажите вашу группу` и нажмите `+` сразу под ним.
2. В списке блоков выберите **Condition / Условие**.
3. Кликните новый блок Condition, откройте настройки.
4. Добавьте правило:

   - Variable: `user_group`;
   - Operator: **contains / содержит** (если такого нет — выберите `is equal to`
     и введите точное значение `СДП-УИР-241`);
   - Value: `СДП-УИР-241`.

5. У блока появятся два выхода — `true` и `false`. Подпишите их, если можно:

   - `Группа найдена`;
   - `Группа не найдена`.

6. Подключите ветки:

   - `true` → текстовый блок `Отлично, Кунда из группы СДП-УИР-241 — данные приняты.`;
   - `false` → текстовый блок `Группа не распознана...`.

7. Если старая связь от Input сразу к тексту осталась — удалите её:
   - наведите на линию-связь;
   - нажмите на появившийся крестик/корзину.
8. Чтобы соединить блоки, перетащите кружок справа от блока на кружок слева
   нужного блока.

## 4. HTTP Request / Webhook

### 4.1. Получите тестовый URL

1. Откройте в новой вкладке https://webhook.site/.
2. Сверху будет надпись `Your unique URL` и адрес вида
   `https://webhook.site/xxxxxxxx-xxxx-...`.
3. Скопируйте этот адрес. Не закрывайте вкладку.

### 4.2. Добавьте блок в TypeBot

1. Вернитесь в редактор.
2. Нажмите `+` после текстового блока успеха.
3. Выберите **Webhook** (иногда в разделе Integrations).
4. Настройте:

   - Method: `POST`;
   - URL: вставьте свой адрес с webhook.site;
   - Body type: `JSON`;
   - Body:

     ```json
     {
       "bot": "lab5-Kunda-SDP-UIR-241-bot",
       "user_name": "{{user_name}}",
       "user_group": "{{user_group}}"
     }
     ```

   - Header: `Content-Type: application/json`.

5. Если TypeBot предлагает выбрать переменные через кнопку_variables —
   используйте её вместо ручного ввода `{{user_name}}`.
6. Подключите выходы:

   - `success` → финальный текст `Спасибо!...`;
   - `error` → текст `Не удалось отправить данные. Попробуйте ещё раз`.

7. Если блока ошибки нет — добавьте его через `+`.
