# Проверка работоспособности бота lab5-Kunda-SDP-UIR-241-bot

Эта инструкция нужна, чтобы доказать: логика, переменные и интеграции
действительно работают, а не только нарисованы в редакторе.

## 1. Проверка переменных

1. Откройте бота в редакторе и нажмите **Preview / Тест**.
2. Введите имя `Иван Кунда`.
3. Введите группу `СДП-УИР-241`.
4. Откройте панель **Variables** и убедитесь, что значения совпадают:

   | Переменная | Ожидаемое значение |
   |---|---|
   | `user_name` | `Иван Кунда` |
   | `user_group` | `СДП-УИР-241` |

5. Сделайте скриншот `04-variables.png`.

## 2. Проверка условия Condition

1. Пройдите диалог с группой `СДП-УИР-241` — должна открыться ветка успеха.
2. Перезапустите диалог и введите группу `TEST-241` — должна открыться ветка ошибки.
3. Убедитесь, что тексты обеих веток на русском.
4. Сделайте скриншот `05-condition.png` в редакторе и `09-result-dialog.png`
   в режиме теста.

## 3. Проверка HTTP Request / Webhook

1. Откройте https://webhook.site/ и оставьте страницу открытой.
2. Скопируйте уникальный URL в блок Webhook.
3. Пройдите успешную ветку диалога.
4. На webhook.site должен появиться POST-запрос с телом примерно таким:

   ```json
   {
     "bot": "lab5-Kunda-SDP-UIR-241-bot",
     "user_name": "Иван Кунда",
     "user_group": "СДП-УИР-241"
   }
   ```

5. Сделайте скриншот `06-http-integration.png`.

## 4. Проверка темы

1. Откройте раздел **Theme**.
2. Убедитесь, что имя бота — `lab5-Kunda-SDP-UIR-241-bot`.
3. Убедитесь, что цвета кнопок и фона отличаются от темы по умолчанию.
4. Посмотрите диалог в превью — текст должен быть читаемым.
5. Сделайте скриншот `07-theme.png`.

## 5. Проверка публикации

1. Откройте публичную ссылку в приватном окне браузера.
2. Пройдите диалог от начала до конца.
3. Проверьте, что ссылка не требует входа в TypeBot.
4. Если подключён Telegram — отправьте боту `/start` и проверьте ветку приветствия.
5. Сделайте скриншот `08-channel-telegram.png`.

## 6. Проверка экспорта

1. В TypeBot откройте **More / Export → JSON**.
2. Сохраните файл как
   `lab5/exports/flow-01-Kunda-SDP-UIR-241-typebot.json`, заменив пример.
3. Убедитесь, что в файле нет поля `example: true` и строки-предупреждения.
4. Проверьте, что имена переменных и бота содержат `Kunda` и `SDP-UIR-241`.

## 7. Проверка репозитория

```bash
git status
git log --oneline
```

Ожидается: рабочее дерево чистое, в истории не меньше 6 коммитов с префиксом `lab5:`.
